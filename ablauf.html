Deep Quiet Uploader – User flow (single user: channel owner)

  1. Owner runs python yt_upload.py --login once and grants access on Google's consent screen (scopes: youtube.force-ssl, yt-analytics.readonly, yt-analytics-monetary.readonly).
  2. Owner finishes an episode; the release folder contains video, title/description (EN + DE), thumbnail and captions.
  3. Owner runs python yt_upload.py releases/<episode> --ki no: the video is uploaded as private with metadata, German localization, thumbnail and captions.
  4. Owner reviews the private video in YouTube Studio.
  5. After approval, owner runs --plan 2026-11-06T23:00: the script sets publishAt; YouTube publishes at that time.
  6. The local dashboard reads the channel's own Analytics (views, likes, watch time, revenue) for the owner.
  7. Access can be revoked any time in the Google Account permissions page; the local token is then deleted.
